# Experiment log and results

Two different places hold run artifacts:

- [`datasets/`](../../datasets/) — shared session JSONL (gitignored) plus manifests.
  Regenerate with the configs; verify sha256 against the manifest.
- `outputs/` — local checkpoints, smoke scratch, and full evaluation dumps.
  Gitignored; nothing there survives a fresh clone.

This folder is the durable run record: a log of every run whose result was used, plus small
summary JSON so the outcome can be checked without re-running or needing `outputs/`.

## Documents

- [benchmark_v4_1_2026-10-30.md](benchmark_v4_1_2026-10-30.md) — benchmark design, gate results,
  learned local ceilings. Gates: `scripts/audit_v4_gates.py`; independent audit:
  `scripts/audit_v4_final.py`.
- [v4_run_checklist.md](v4_run_checklist.md) — GPU ladder, go/no-go, pre-registered slices.
- [log.md](log.md) — one row per run.

## Running

1. Keep the config under [`configs/`](../../configs/) (generated by `scripts/make_v4_configs.py`).
2. Use the frozen `datasets/metro_v4_1/`; the ladder checks every sha256 against its manifest.
3. Record the exact git commit in the log.

## After running

1. Append one row to [`log.md`](log.md).
2. Copy result JSON (no checkpoints, no session JSONL) to `results/<run-id>/`.

## Layout
